1. Sistemas de Información Ambiental Oficiales SIAC

El SIAC es el "sistema de sistemas" que articula la información ambiental oficial. Cada subsistema tiene geovisores, APIs y descargas de capas.

Sistema Portal Principal Portal de Datos / Descargas Descripción
SIAC https://www.siac.gov.co/ https://datos.siac.gov.co/ Nodo central - geovisor, catálogo mapas, datos abiertos
SIRH https://portalsirh.minambiente.gov.co/ https://sirh.ideam.gov.co/ Sistema Información Recurso Hídrico - concesiones, calidad, oferta/demanda
SISAIRE http://sisaire.ideam.gov.co/ Portal IDEAM SISAIRE Calidad aire nacional - PM2.5, PM10, gases, ruido (admin. IDEAM)
SNIF http://snif.ideam.gov.co/ Portal IDEAM SNIF Información forestal - aprovechamiento, movilización, incendios, carbono
RUNAP https://runap.parquesnacionales.gov.co/ Visor RUNAP Registro áreas protegidas SINAP - categorías, ubicación, planes manejo
RESPEL https://rua-respel.ideam.gov.co/ Guía migración a RUA Generadores residuos peligrosos (hasta dic 2025)
RUA https://rua.ideam.gov.co/ Portal IDEAM RUA Registro Único Ambiental - obligatorio desde 2026 (Res. 839/2023)
VITAL https://vital.minambiente.gov.co/ https://vital-publico.minambiente.gov.co/ Trámites ambientales en línea - licencias, permisos, concesiones

11. Guías de Acceso Rápido por Temática QUICK REF

🔍 Para licenciamiento ambiental

  1. VITAL → vital-publico.minambiente.gov.co
  2. ANLA → ANLA - VITAL
  3. Decreto 1076 Libro 2 → Cancillería - Decreto 1076

💧 Para agua y vertimientos

  1. Resolución 631/2015 (límites) → PDF directo
  2. SIRH → portalsirh.minambiente.gov.co
  3. POMCA → SIRH - POMCA

🌬️ Para calidad del aire

  1. Resolución 2254/2017 (norma) → PDF directo
  2. SISAIRE → sisaire.ideam.gov.co
  3. SIATA (Valle Aburrá) → siata.gov.co
  4. PIGECA/POECA → metropol.gov.co

🌳 Para biodiversidad y áreas protegidas

  1. RUNAP → runap.parquesnacionales.gov.co
  2. Instituto Humboldt → humboldt.org.co/consulta
  3. SiB Colombia → sibcolombia.net
  4. Parques Nacionales → parquesnacionales.gov.co

♻️ Para residuos peligrosos

  1. RESPEL → rua-respel.ideam.gov.co (hasta dic 2025)
  2. RUA → rua.ideam.gov.co (desde 2026 - Res. 839/2023)
  3. Resolución 1362/2007 → MinAmbiente - Residuos

🌡️ Para cambio climático

  1. NDC 3.0 → UNFCCC PDF
  2. Ley 1931/2018 + Ley 2169/2021 → enlaces sección normativa
  3. SNICC → MinAmbiente - SNICC
  4. RENARE → renare.ideam.gov.co

curl -I https://www.ideam.gov.co/

ls -lh *.pdf
