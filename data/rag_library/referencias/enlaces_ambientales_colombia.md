## 11. Guías de Acceso Rápido por Temática

### 🔍 **Para licenciamiento ambiental**
1. VITAL → https://vital-publico.minambiente.gov.co/
2. ANLA → https://www.anla.gov.co/01_anla/vital-ventanilla-integral-de-tramites-ambientales-en-linea
3. Decreto 1076 Libro 2 → https://www.cancilleria.gov.co/normograma/compilacion/docs/decreto_1076_2015.htm

### 💧 **Para agua y vertimientos**
1. Resolución 631/2015 (límites) → PDF arriba
2. SIRH → https://portalsirh.minambiente.gov.co/
3. POMCA → https://portalsirh.minambiente.gov.co/planes-de-ordenacion-y-manejo-de-cuencas-hidrograficas-pomca

### 🌬️ **Para calidad del aire**
1. Resolución 2254/2017 (norma) → PDF arriba
2. SISAIRE → http://sisaire.ideam.gov.co/
3. SIATA (Valle Aburrá) → https://siata.gov.co/
4. PIGECA/POECA → AMVA

### 🌳 **Para biodiversidad y áreas protegidas**
1. RUNAP → https://runap.parquesnacionales.gov.co/
2. Instituto Humboldt → https://www.humboldt.org.co/consulta
3. SiB Colombia → https://www.sibcolombia.net/
4. Parques Nacionales → https://www.parquesnacionales.gov.co/

### ♻️ **Para residuos peligrosos**
1. RESPEL → https://rua-respel.ideam.gov.co/ (hasta dic 2025)
2. RUA → https://rua.ideam.gov.co/ (desde 2026 - Resolución 839/2023)
3. Resolución 1362/2007 → https://www.minambiente.gov.co/asuntos-ambientales-sectorial-y-urbana/residuos-peligrosos

### 🌡️ **Para cambio climático**
1. NDC 3.0 → UNFCCC (PDF arriba)
2. Ley 1931/2018 + Ley 2169/2021 → enlaces arriba
3. SNICC → https://www.minambiente.gov.co/cambio-climatico-y-gestion-del-riesgo/sistema-nacional-de-informacion-sobre-cambio-climatico-snicc
4. RENARE → https://renare.ideam.gov.co/
